# Final status

Prototype scope: local Python camera/dashboard MVP, now defaulting to the bundled OpenCV Zoo YOLOX-s COCO detector, existing greedy-IoU tracker, and public-area event review with operator-configured image zones, transition and loiter rules. The model runs locally and is included in the ZIP; its upstream COCO metrics are not validation for this application's camera scenes. Local event warnings may include message drafts for operator review only; no notification or emergency call is sent. `python app.py --demo` runs a clearly marked synthetic fixture, not a live detection test. Optional BoT-SORT and Ultralytics adapters, latency-aware advisory lead positions, and homography localization remain available. The separate Gemma scene assistant remains disabled unless explicitly configured and consented. Hand-gesture events require a configured detector class and remain unavailable with the default person detector; face, identity, emotion and gaze analysis are excluded. No representative public-area validation is included. See DEMO.md, PUBLIC_AREA.md, LIMITATIONS.md, DRONE_MIGRATION.md, and README.md before deployment.
